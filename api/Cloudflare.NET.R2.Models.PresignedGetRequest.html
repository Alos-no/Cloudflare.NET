Parameters

Key string

The object key (path) of the file to be downloaded from the bucket.

ExpiresAfter TimeSpan

The duration for which the presigned URL will be valid.

ResponseContentType string

An optional response-content-type override. Because the override is part of the signed query string, R2 stamps it as the Content-Type header of its response, and the URL holder cannot alter it after signing.

ResponseContentDisposition string

An optional response-content-disposition override. Because the override is part of the signed query string, R2 stamps it as the Content-Disposition header of its response (e.g. an attachment directive carrying a save-as filename), and the URL holder cannot alter it after signing.
