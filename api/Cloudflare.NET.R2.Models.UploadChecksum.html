Examples

// From raw digest bytes computed locally:
var checksum = UploadChecksum.FromDigestBytes(R2ChecksumAlgorithm.Sha256, SHA256.HashData(fileBytes));

// From untrusted strings a client supplied:
if (!UploadChecksum.TryCreate(request.Algorithm, request.Digest, out var uploadChecksum))
    return BadRequest("Unknown checksum algorithm or malformed digest.");

Remarks

Passing an instance to PresignedPutRequest, PresignedUploadPartRequest or PresignedUploadPartsRequest signs the algorithm's header (HeaderName) into the URL. The client must then send that exact header, or the signature no longer matches and R2 answers 403. When the client does send it, R2 hashes the arriving bytes and rejects the upload with 400 BadDigest if they do not hash to the stated digest, storing nothing.

The constructor rejects a digest whose base64 text is malformed or whose decoded length is not exactly what the algorithm produces, so a URL is never signed for a digest R2 could not possibly accept. Use TryCreate(string?, string?, out UploadChecksum?) to validate untrusted algorithm and digest strings without exceptions, such as values arriving in an API request.
