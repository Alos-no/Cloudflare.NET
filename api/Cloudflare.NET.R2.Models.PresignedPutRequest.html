The MIME type of the file to be uploaded (e.g., "image/jpeg"). This is enforced by R2.

Conditions IEnumerable<S3PostCondition>

Optional S3 POST policy conditions to enforce additional constraints on the upload.

HeadersToSign IReadOnlyDictionary<string, string>

An optional dictionary of additional headers to include in the signature, enforcing them on the client-side upload.

Checksum UploadChecksum

An optional digest to bind the uploaded bytes to. Its algorithm's header is signed into the URL, the client must send it, and R2 rejects the upload with 400 BadDigest (storing nothing) when the arriving bytes do not hash to the stated digest. All five R2ChecksumAlgorithm values are verified on a single-part PUT. When the same header also appears in HeadersToSign, this parameter wins.

CacheControl string

An optional Cache-Control value to store on the object. The header is signed into the URL, so the client must send it with exactly this value or R2 answers 403; R2 persists the stored value and serves it on every GET, which drives edge and browser caching. Passing null or a blank string leaves the header unset. When the same header also appears in HeadersToSign, this parameter wins.
